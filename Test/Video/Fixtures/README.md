These deterministic Ogg/Theora video fixtures are generated by `generate.cpp`.
The audio fixture is an original sine wave from `generate-audio.cpp`.
All fixtures use the project's MIT license and contain no third-party media.
The encoder is only needed to regenerate fixtures; running the tests needs only
the decoder already vendored in Dora-SSR.

- `motion.ogv`: 600 frames, 64×64, 30 fps; moving patterns, interframes, keyframes
  every 64 frames, and a repeated-image interval at frames 250–279.
- `continued.ogv`: four 384×384 noise keyframes. Packets span multiple Ogg pages;
  seeking must retain packets which begin after a continued packet on a page.
- `1080p.ogv`: 45 frames, 1920×1080, 30 fps, for native buffer/backpressure checks.

Regenerate with libtheora 1.2.0 and libogg:

```sh
c++ -std=c++17 generate.cpp $(pkg-config --cflags --libs theoraenc) -o generate
./generate motion.ogv 64 64 600
./generate continued.ogv 384 384 4 noise
./generate 1080p.ogv 1920 1080 45
```

- `tone.ogg`: 1.25 seconds of an original 440 Hz stereo sine wave, 44.1 kHz.
  Audio tests mux it with `motion.ogv` in both BOS orders without re-encoding.
  The EOF regression increases SoLoud's reported sample count by 1024 to
  reproduce the original OGV's metadata/decoded-PCM mismatch deterministically.

```sh
c++ -std=c++17 generate-audio.cpp $(pkg-config --cflags --libs vorbisenc ogg) -o generate-audio
./generate-audio tone.ogg
```
