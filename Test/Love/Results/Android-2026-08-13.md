# Android Love open-source corpus report — 2026-08-13

## Result

The pinned 100-game corpus completed on the Android emulator after the Love
compatibility fixes. Each game was uploaded through the Web IDE entry point,
launched in a fresh application process, and observed for up to 120 engine
frames.

| Status | Games |
| --- | ---: |
| `pass` | 76 |
| `init-failed` | 22 |
| `runtime-failed` | 1 |
| `workflow-failed` | 1 |
| `app-exited` | 0 |
| `transient-failed` | 0 |
| **Total** | **100** |

The complete per-game result and captured diagnostic are in
[`Android-2026-08-13.tsv`](Android-2026-08-13.tsv). Failed cases remain in the
denominator and were audited rather than silently excluded.

## Non-pass audit

The 24 non-pass results do not identify a remaining Android graphics or Love API
compatibility defect that can be fixed without changing the tested game or the
documented LuaJIT boundary:

| Classification | Cases | Evidence |
| --- | --- | --- |
| Incomplete game checkout/package or non-Love module | 1, 14, 22, 23, 26, 35, 47, 48, 50, 52, 53, 59, 88, 96, 97, 98 | Missing native module, asset, source module, submodule, or required save file. The same exact packages fail under official Love 11.5 where compared. |
| Explicit LuaJIT/native ABI boundary | 15, 68, 70, 95 | These games require LuaJIT `ffi` (and case 95 also integrates native Discord code). Dora intentionally runs the isolated Love state on Lua 5.5 and does not expose LuaJIT/native-module ABI loading. |
| Game source also fails on official Love 11.5 | 56, 73, 89 | The fixed packages reproduce their removed API/invalid call or shader failure on official Love 11.5, so they are not Dora Android regressions. |
| Harness time budget | 74 | The app stayed alive with no Love error. A focused cold-start run passed at 5 frames; its rendering is about two seconds per frame on this emulator, so the 120-frame run exceeded both the original 60-second and a diagnostic 180-second wait. |

The compatibility repairs promoted 22 previously failing candidates to Android
passes: 28, 29, 31, 32, 37, 38, 39, 40, 44, 45, 58, 61, 65, 66, 76, 81, 85,
90, 91, 92, 93, and 94. These cover LuaJIT-era module loading and numeric-loop behavior,
window/canvas and scissor overloads, physics fixture enumeration, shader
translation, save-relative `io`, `love.load(arg)`, and thread-side ImageData
decoding.

## Transient-buffer regression

No game produced a `not enough transient buffer` diagnostic and no Dora process
exited during the 100-game run. The result therefore also preserves the earlier
transient-buffer lifecycle fix across 100 cold application starts and repeated
LoveNode teardown/recreation.

This is an automated startup/render smoke test, not a claim that every gameplay
path, input method, audio path, or level was exercised.
